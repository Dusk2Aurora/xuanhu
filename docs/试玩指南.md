## 二、多床位怎么用

1. 菜单 → **病房床位**
2. 点 **「开一个新病例（占用空床）」** → 占一张新床
3. 最多 **4 张床**，所有床的时间**同步流逝**
4. 底部胶囊 `床位 ① ② 2/4` 显示各床状态，点它直接切床
5. 哪张床出院或死亡 → **自动结算并释放**，后台床也会静默记进手册
6. 怕漏掉后台床出事？**后台床出现室颤、心停、血氧 <80、血钾 >7、收缩压 <70 会弹提示并报警**

> 「切换病例」是**替换当前床**，不是新开——想加床请走「病房床位」。

## 四、难度怎么选

两件事分开：

- **病例难度 1–5**：决定病有多复杂（合并症、体质、病情进展速度）
- **指导强度**：学习 / 实习 / 住院医 / 主治 / 专家
  - 学习、实习：自动提示，给到具体步骤
  - 住院医：问了才答，只给方向
  - 主治：只给结论
  - 专家：无提示，正常值也隐藏

> 「不靠上级」（主治/专家模式独立出院）、「零提示」（专家模式零扣分）是成就。

## 六、给新手的三个建议

1. **先看上级医师的提示**——它会告诉你"现在最危险的是什么"，但不会替你按按钮
2. **先保命，再查因**：气道/呼吸/循环 → 再谈诊断
3. **允许犯错**：给错药会被扣分并记进手册，但不会直接判死（除非真的致命）——错了才知道为什么错
