# 病理与处置反馈复核

本文记录游戏内的复现和判定。下列时间均为模拟时间，各项数值用于验证模拟行为。

| 反馈主题 | 核查及处理 |
| --- | --- |
| 处置扣分、急诊首诊与带教 | 明确的误操作逐次写入操作日志和结算，骤停单独结算。普通难度按下单前病情评估，避免同一处置重复扣分。急诊首诊取消隐藏带教扣分。评分说明列明覆盖范围。 |
| 颅压与 GCS | 合并了同一颅压在 GCS 中的两次减项。低血糖、低灌注、镇静等独立因素仍可共同影响意识。 |
| 降温与出院 | 热射病在 38.5℃ 停止主动降温，脱离热环境后可继续恢复。日志说明停止的是降温处置，出院评估列出 36.0–37.8℃ 的范围，病例和带教提示指向操作栏的体温处置。 |
| 室颤与死亡时钟 | 高钾等诱因解除后室颤风险逐步消退，持续的心梗缺血在一小时后仍可引发室颤。极低灌注按实际持续时间判定，恢复后重新计时。 |
| 溶栓、解毒与其他药效 | 本版的阿替普酶、碳酸氢钠、解磷定已按给药途径与实际剂量起效。相邻的病例模型仍有仅凭医嘱存在就获得足量作用的情况，现将降压、解痉等病例效应接入药效时程。 |
| 甘露醇 | 开单已有输注时间，颅压随已输剂量改变。补上反复输注蓄积的肾脏影响，去掉与颅压无关的直接意识加分。过量效应为游戏近似。 |
| 呼吸机与慢性二氧化碳潴留 | 机控可调频率、流量与氧浓度，低氧时保留设定。达到目标潮气量后，流量仍影响吸呼时间及阻塞患者有效通气。仅就病例已知的慢性高碳酸基线补偿碳酸氢盐，保留急性酸碱变化。 |
| 透析指征、降钾及采样 | 尿潴留继发重度高钾可获得透析带教。分别验证间歇血透、CRRT、试撤、恢复、停机，与同病例未治疗对照比较。间歇血透显示运行进度，CRRT 读数注明采样时刻。 |
| 开颅与影像证据 | 头颅 CT 周转 8 分钟。按近期影像中的血肿大小、必要时结合神经查体判断开颅依据，等待影像和已明确无指征的处置分别处理。 |
| 新旧药库 | 去甲肾上腺素泵的效应已经参与除颤判定。修正现代药库胺碘酮未参与该判定，以及用过奥美拉唑后带教仍提示补用的问题。保留旧药效记录的读取。 |
| 高低钙、体温和症状 | 钙异常影响监护波形及 12 导联 QT，重度异常可在床旁查体见到相关体征。非设备所致低体温也影响代谢与循环，寒冷环境下有寒战代偿，深低体温可增加室性心律失常风险。病例目标调整为可核实的量，不再要求完成未独立建模的主观疼痛评分。 |
| 其余报告判断 | 既有肾小球滤过率会影响碳酸氢盐再生，发热超过 37℃ 已会增加耗氧。常规氧疗、设备费用归集均有独立检查。特殊设备费用与普通费用分别结算，游戏继续采用既有计分规则。 |

## 董伟的三次撤氧

原始会诊码校验值为 `vw0a`，可重建 v1.57.3 难度 6、生成器 7、种子 586365968 的 83 岁患者，以及 36 条用药记录。原码没有逐时体征、供氧流量、CRRT 时段、导尿时间或尿量。以下为旧版引擎的对照重演。按玩家记录在 00:09 完成 PCI，24:38 停氧、24:39 复氧，25:16 停氧、25:23 复氧，25:53 再次停氧。主要对照假设到院即导尿、供氧期间流量 60 L/min，未补入时间不详的 CRRT。每步推进 0.2 秒。肺水为游戏指数。

| 撤氧时刻 | 撤氧前 10 分钟、5 分钟及当时的肺水 | 旧版重演的 SpO₂ | 同条件仅修复死腔后的 SpO₂ |
| --- | --- | --- | --- |
| 24:38 | 0.497 → 0.528 → 0.561 | 撤氧前 99.39%，1 分钟后 96.27%，复氧 1 分钟后 97.53% | 99.39% → 96.33% → 97.57% |
| 25:16 | 0.508 → 0.466 → 0.418 | 撤氧 7 分钟后 95.89%，持续供氧对照 99.97% | 撤氧 7 分钟后 96.51% |
| 25:53 | 0.139 → 0.094 → 0.051 | 28:08 室内空气 94.87% | 28:08 室内空气 95.41% |

19:40 停多巴酚丁胺并开始输液后，至 20:00 心输出量从 3.64 降到 3.39 L/min，此时肺水仍为 0.05。22:00 至 24:00，有效收缩力指数 0.446 → 0.443，外周血管阻力 20.65 → 24.83，肺毛细血管楔压 19.6 → 22.4 mmHg，心输出量 3.21 → 2.79 L/min。左心衰病例自带的血管收缩驱动从 1.45 升至 5.98，难度 6 在此例将病例病程推进乘以 1.96。22:15 肺水才从最低值升至 0.053，23:44 起越过造成额外分流的 0.25。PCI 后的左心衰病程仍在推进。

22:00 至 24:00 没有静脉补液医嘱。系统维持入液约 115 mL，尿量约 119 mL，差额约 −4 mL。同期血管内容量 4.857 → 4.925 L，是模型中液体在血管和组织之间分配的结果。全程分享码内的生理盐水共 3 L。零超滤假设下，计入游戏的维持入液和尿量，重演的全程净入量约 +1.74 L。原局实际液体平衡无法从会诊码取回。

第二次撤氧前肺水已在下降。24:39 的舌下硝酸甘油和 24:46 的呋塞米均已给入。25:23:36 才开始的 500 mL 盐水按 15 分钟输注。固定其他条件后，25:24 复氧组给液与不给液的 SpO₂ 都为 99.71%，继续室内空气的两组约为 95.7%。至 25:38，给液组和对照组的 MAP 分别为 70、68 mmHg，心输出量为 3.40、3.29 L/min，肺水为 0.187、0.178。这个对照可区分当分钟的复氧效果和稍后补液的循环影响。

原记录第二次撤氧从 100% 降到 90%，该幅度未能精确复现。另设 22:00 至 23:44 开启 CRRT 的对照，末次血压可达到玩家记录的 87/72、MAP 77，第二次撤氧仍约为 95.7%。末次体征接近，仍不足以反推原局的 CRRT 开停时间或当时的肺水。

**确认并修复的缺陷。** 旧代码将肺水引起的峰值死腔重新当作基础死腔，此例后半程一直为 0.483。修复后，三次撤氧起点的死腔比例分别为 0.386、0.360、0.330。肺水、气道阻塞、肺栓塞和慢性肺病分别参与当前计算，旧存档按基础病和现状恢复。

## 高钾病例的透析对照

同一例高钾病例，起始血钾均为 6.90 mmol/L。分别选择单项治疗，其他条件一致。

| 处理 | 第 30 分钟 | 第 60 分钟 |
| --- | ---: | ---: |
| 未治疗 | 7.25 | — |
| 间歇血透 | 5.65 | 4.93 |
| CRRT 持续运行 | 6.22 | 5.77 |
| CRRT 第 30 分钟试撤 | 6.22 | 6.57 |

试撤组在第 60 分钟恢复 CRRT，第 90 分钟回落至 6.00。另一个样本在试撤开始时采血，35 分钟后出报告仍应显示采样时的 4.5，试撤后的变化要用后续采样核对。重度高钾若已积累心律失常风险，血透启动与血钾下降之间还有时间差。

- 开颅的主要依据为影像占位及神经恶化。游戏中的检查周转时间和资料有效期用于安排病例节奏。[Brain Trauma Foundation 手术指南](https://braintrauma.org/coma/guidelines/surgical)
