# 更新说明：v0.9.0 → v1.18.0

> 这一版的核心是**把生理模型从"剧本化"改成"机制驱动"**，并把内容从 14 个病例扩到 22 个。

---

## 一、病不再"按剧本走"

**以前**：每个病例有一个"疾病负荷变量"按时间线性推进，然后直接给体征设上限。
→ 结果：不治疗也会自己好（感染性休克 4 分钟 MAP 从 64 回到 76、肺水肿 6 分钟血氧从 86 回到 99），治疗的唯一作用是把计时器调快。

**现在**：模块只改变**底层负荷量**，体征全部由引擎按生理方程算出来。

| 病例 | 模块只写这个 | 体征从哪来 |
|---|---|---|
| 哮喘 | 气道阻力 | 肺泡通气 → 分流 → Hill 方程 → 血氧 |
| 有机磷 | 胆碱酯酶活性 | 乙酰胆碱蓄积 → 心率/分泌/支气管痉挛 |
| 肺栓塞 | 肺血管阻力 | 右心后负荷 → 每搏量↓ → 梗阻性休克 |
| 肺水肿 | 肺毛细血管压 | Starling → 肺水 → 分流 → 低氧 |
| 低钠 | 游离水 | 渗透压 → 颅压 → 意识 |
| 对乙酰氨基酚 | NAPQI / 谷胱甘肽 | 肝损 → 凝血/肌酐/乳酸 |
| 张力性气胸 | 胸腔内压 | 腔静脉受压 → 前负荷↓ → 梗阻性休克 |
| 心包填塞 | 心包内压 | 同上但机制不同，处理也不同 |
| 热射病 | 产热驱动 | 体温 → 代谢/意识 |
| 一氧化碳 | 碳氧血红蛋白 | 功能性血红蛋白↓ → DO₂↓，而 SpO₂ 看着正常 |

**结果：不治疗死亡率从 5/14 提升到 109/110，22 个病例死因各不相同。**

## 三、新增机制

- **氧输送 DO₂** = CO × Hb × SaO₂ × 1.34：贫血/低氧/休克/CO 中毒统一走这条通路
- **分流方程**：哮喘/肺水肿/肺栓塞/有机磷/胰腺炎各自贡献，互不干扰
- **HCO₃ 状态量**：从拟合公式改成生成−消耗微分方程
- **红细胞质量**：失血先丢容量、补液后才稀释
- **颅压 ODE**：低钠/高血压脑病 → 脑水肿 → 脑疝
- **药物 Emax 饱和**：剂量翻倍不再效应翻倍
- **体重给药**：12 种按 kg 计量的药按 体重/70 缩放
- **药物相互作用**：18 条高危组合
- **特殊体质**：9 种（β-内酰胺过敏、长 QT、哮喘史、CKD、糖尿病、G6PD、慢代谢、高血压、老年）
- **环境**：炎热/寒冷/运动/睡眠

## 四、新内容（14 → 26 个病例，17 个操作，190 种物质）

## 六、诊断与手册

- **诊断分类器**：28 种诊断，从指标组合反推，给置信度 + 证据链 + 需排除项

## 八、还没解决的

1. **高渗高血糖**的治疗窗口偏长（200 min），可能需要缩短
2. **药物相互作用是一次性注入**，与药物代谢时程不同步
3. **复张性肺水肿**未建模（急性 30 min 张力性气胸可接受）
4. **奇脉/吸气性收缩压下降**等心包填塞特征未建模
5. 外伤模块只有 3 个病例，颅脑外伤、烧伤未做
