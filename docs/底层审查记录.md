# 药理与生理引擎审查记录

基线为上游 `8438bfc`。以下结论对应模拟器的行为与回归用例。

| 范围 | 复现与结论 | 验证入口 |
| --- | --- | --- |
| 时间推进与置管完成事件 | `36b2aa8` 引入按置管完成时间拆分步长。旧的最小时间步会让零秒调用改变患者状态。现由引擎与病例推进入口共同拒绝非正或非有限步长。 | `tools/regression-physio.js`、`tools/vascular-access-test.js` |
| 病例灌注压力 | 烧伤病例传入 MAP 0 时曾返回空的低血压原因列表。病例判定及出血驱动现在保留实测零值。回归覆盖 0 和阈值 68。 | `tools/regression-physio.js` |
| 给药入口 | 床旁开单已有剂量校验。直接调用引擎时，零剂量纳洛酮和钙剂仍各自产生 2700 秒标记。显式无效剂量现在在写医嘱、计费和产生作用之前返回。省略剂量仍沿用目录默认值。 | `tools/drug-billing-test.js` |
| 定时输注、持续泵与重载 | 对照 `8a326c8` 对停泵和零剂量撤药的修复。现有用例遍历目录里的输注途径，另行检查肝素与艾司洛尔的分段泵量、暂停、恢复和费用。这部分覆盖当前格式的读档与已有迁移样例。 | `tools/drug-billing-test.js`、`tools/ix-pk-test.js` |
| 目录与途径 | 遍历 227 个条目、251 种条目与途径组合，检查重复标识、重复途径、默认途径、默认剂量及其上限。直接给药曾接受“静推水”和“纳洛酮贴剂”，写入用药史并计费。现对药品库、饮食条目和旧目录检查途径；保留持续泵别名。 | `tools/drug-billing-test.js`、`tools/ix-pk-test.js` |
| 按体重计量 | 对照氯胺酮补丁 `2505b4c`。同一参考剂量的右美托咪定在 50 和 100 kg 患者产生了 0.714 和 1.429 倍归一化暴露。常规药效使用同单位剂量之比计算强度。凝血因子补充和 MTX 裂解在救援模块内完成浓度换算，继续传入总量；价格仍按实际用量缩放。已有医嘱沿用保存的强度，避免读档时药效突变。逐途径覆盖目录中全部按公斤计量条目。 | `tools/drug-billing-test.js` |
| 相互作用 | 40 组相互作用的两端均能匹配目录名称。旧提示仅在普通给药时查 PK 列表，遗漏连续泵。覆盖两组涉及持续泵的组合及两种开单顺序，另查零输入即停泵、去重及既有清除时间窗。 | `tools/ix-pk-test.js` |
| 联合药效与阿片拮抗 | 核对 40 条规则的效应字段与引擎分派。追溯 `83e2c3a` 和 `81403e4`：原先阿片受阻后仍进入共同暴露计算；纳洛酮还会独立提高呼吸和意识修正值。改由专用拮抗机制生效，涵盖旧医嘱。三组阿片与镇静药组合分别比较拮抗中和消退后的修正值，另以无阿片对照检查旧档。此项验证覆盖效应分派和上述组合，未校准其余组合的临床效应量。 | `tools/ix-pk-test.js`、`tools/mechanism-test.js` |
| 氧合与血气 | 对照 `83e2c3a` 的含量混合和旧档迁移。旧档毛细血管末端分压 25 mmHg、静脉饱和度 80%、分流 50% 时，恢复后动脉分压反升至 32.37 mmHg。现遇到不相容的静脉初值即按氧耗和血流重算，并约束混合反解上界。核对无分流、有分流、监护读数和床旁血气采样。既有用例另覆盖撤氧、COHb 和原血气报告保留。 | `tools/regression-physio.js`、`tools/exams-test.js` |
| 高级设备与控温 | 对照 `fd939ea` 和 `81403e4`，核查六种设备的启动、互斥、试撤、停机、计费与存档恢复。复温在第 30 秒结束时，一次推进 120 秒曾丢掉后 90 秒自然体温变化；冷却完成日志也曾取步末时间。回归用同一病例对照整步和读档后拆步，检查体温、事件时刻及费用。 | `tools/advanced-devices-test.js`、`tools/exploration-emergency-test.js` |
| 肾脏与体液 | 对照 `059ac96` 的透析有效时长和 `46a0924` 的结束回执。肌酐为 30 µmol/L 时，清除项曾将其抬到 40；现限制清除方向并按实际停机时刻写日志。另复现正自由水负荷下，单纯自由水清除错误扣除钠质量（示例中 1680 → 1679.4 mmol），但该变量也承载含钠补液。直接删除排钠项使低钠和高渗病例在 6 小时模拟内均为 0/5 出院，未纳入此补丁。后续修复见下行。核查 CRRT 超滤、钾和碳酸氢盐的时长项及透析间期留观。 | `tools/regression-physio.js`、`tools/advanced-devices-test.js` |
| 自由水与等渗扩容 | 采用现有钠总量、入院钠浓度、基础稀释容积与水负荷，估算可随扩容排出的钠水，并保留纠正原有高钠所需的水。四组质量平衡对照覆盖纯水、等渗、混合负荷和既有水缺失。此处是游戏内简化，未引入尿钠实测值。 | `tools/regression-physio.js`、`tools/content-test.js` |
