# 药理与生理引擎审查记录

基线为上游 `8438bfc`。以下结论对应模拟器的行为与回归用例。

| 范围 | 复现与结论 | 验证入口 |
| --- | --- | --- |
| 时间推进与置管完成事件 | `36b2aa8` 引入按置管完成时间拆分步长。旧的最小时间步会让零秒调用改变患者状态。现由引擎与病例推进入口共同拒绝非正或非有限步长。 | `tools/regression-physio.js`、`tools/vascular-access-test.js` |
| 病例灌注压力 | 烧伤病例传入 MAP 0 时曾返回空的低血压原因列表。病例判定及出血驱动现在保留实测零值。回归覆盖 0 和阈值 68。 | `tools/regression-physio.js` |
| 给药入口 | 床旁开单已有剂量校验。直接调用引擎时，零剂量纳洛酮和钙剂仍各自产生 2700 秒标记。显式无效剂量现在在写医嘱、计费和产生作用之前返回。省略剂量仍沿用目录默认值。 | `tools/drug-billing-test.js` |
| 定时输注、持续泵与重载 | 对照 `8a326c8` 对停泵和零剂量撤药的修复。现有用例遍历目录里的输注途径，另行检查肝素与艾司洛尔的分段泵量、暂停、恢复和费用。这部分覆盖当前格式的读档与已有迁移样例。 | `tools/drug-billing-test.js`、`tools/ix-pk-test.js` |
| 目录与途径 | 遍历 227 个条目、251 种条目与途径组合，检查重复标识、重复途径、默认途径、默认剂量及其上限。直接给药曾接受“静推水”和“纳洛酮贴剂”，写入用药史并计费。现对药品库、饮食条目和旧目录检查途径；保留持续泵别名。 | `tools/drug-billing-test.js`、`tools/ix-pk-test.js` |
| 按体重计量 | 对照氯胺酮补丁 `2505b4c`。同一参考剂量的右美托咪定在 50 和 100 kg 患者产生了 0.714 和 1.429 倍归一化暴露。常规药效使用同单位剂量之比计算强度。凝血因子补充和 MTX 裂解在救援模块内完成浓度换算，继续传入总量；价格仍按实际用量缩放。已有医嘱沿用保存的强度，避免读档时药效突变。逐途径覆盖目录中全部按公斤计量条目。 | `tools/drug-billing-test.js` |
| 相互作用 | 40 组相互作用的两端均能匹配目录名称。旧提示仅在普通给药时查 PK 列表，遗漏连续泵。覆盖两组涉及持续泵的组合及两种开单顺序，另查零输入即停泵、去重及既有清除时间窗。 | `tools/ix-pk-test.js` |

仍待逐项审查药物目录的单位和途径、相互作用、器官反馈、病例生成、设备和处置，以及对应存档迁移。既有测试通过仅说明覆盖的行为符合断言。
