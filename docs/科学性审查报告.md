## 三、模型的关键假设（已知简化）

1. **单室药代 + 平台效应**：药物浓度用一阶动力学近似，不区分房室；大剂量时用饱和平台，避免"翻倍剂量翻倍效应"。
2. **氧合用分流方程**：`SaO₂ = (1−Qs/Qt)·Hill(PaO₂) + Qs/Qt·SvO₂`，SvO₂ 由 Fick 方程（VO₂/DO₂）推。分流上限 35%。
3. **没有肾小管精细调节**：尿量 = 肾灌注 × 容量因子 + 利尿剂项；不建模髓袢逆流倍增。
4. **酸碱用简化 Henderson–Hasselbalch 驱动**：pH 由 PaCO₂ 与 HCO₃ 推出，不建模磷酸盐/蛋白缓冲。
5. **凝血只到"凝血倾向"一个标量**：不建模 PT/APTT/纤维蛋白原/D-二聚体的完整级联（D-二聚体是独立状态量，只做提示）。
6. **体温**：感染、环境、药物、内分泌分别驱动，钳制在 30–43.5℃。
7. **时间尺度**：1 秒真实 ≈ 1 秒游戏（可 4×/16×/快进），病理进展速度按难度倍率放大。

## 五、仍需人工把关的部分

1. **儿童/孕妇剂量**未单独建模（目前成人通用，孕妇只有子痫前期一例）
2. **肝肾功能不全的剂量调整**只做到"代谢减慢"，没有逐个药物调整
3. **罕见病与遗传病**未覆盖
4. 病例文案的**临床表述**建议由有执照的医师终审
