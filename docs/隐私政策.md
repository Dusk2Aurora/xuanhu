# 悬壶 · 隐私政策

**生效日期：2026 年 11 月 27 日**
**适用版本：v1.49.x 及以后**

---

## 一、我们收集哪些信息

**我们不收集你的个人身份信息。**

具体来说：

| 类型 | 是否收集 | 说明 |
|---|---|---|
| 姓名、手机号、身份证号 | ❌ 不收集 | 游戏没有任何账号系统 |
| 位置信息 | ❌ 不收集 | 不申请定位权限 |
| 通讯录、相册、短信 | ❌ 不收集 | 不申请相关权限 |
| 设备唯一标识（IMEI/IDFA） | ❌ 不收集 | 不做设备追踪 |
| 游戏进度 | ✅ 仅存本地 | 存在你设备浏览器的 localStorage 里，不上传 |

## 二、游戏过程中产生的数据

### 1. 游戏进度（本地）

- 存放位置：你设备的本地存储（Android WebView / 浏览器 localStorage）
- 内容：床位、病例、行医手册记录、成就、设置
- 是否会离开你的设备：**不会**，除非你主动导出

清除浏览器数据或卸载应用会删除这些内容，我们无法恢复。

### 2. 你主动提交的反馈（可选）

当你在游戏内点击「反馈问题」并选择提交时，会发送：

- 游戏版本号、运行平台（网页版/安卓）
- 当前病例名称、病人信息（**游戏内随机生成的虚构人物**，不是真人）
- 当前生命体征数值与最近的操作记录
- 你在"问题描述"里自己写的内容

**这些数据只用于定位和修复问题。** 如果你不点击提交，什么都不会发送。

### 3. 不会自动上传任何数据

游戏不会在后台自动上传数据，也没有埋点统计、广告 SDK、第三方分析工具。

## 三、权限说明

安卓版仅申请以下权限：

| 权限 | 用途 |
|---|---|
| `INTERNET` | 检查更新、加载在线版（可选）、提交反馈（可选） |

不申请存储、相机、麦克风、定位、通讯录等权限。

## 四、第三方服务

| 服务 | 用途 | 涉及数据 |
|---|---|---|
| Netlify | 托管网页版与更新文件 | 服务器会记录常规访问日志（IP、时间、UA），这是所有网站的通行做法 |
| GitHub Pages | 托管网页版和离线下载 | GitHub 会记录访问者 IP 地址用于安全维护；选择在 GitHub Issues 发布的反馈会公开显示 |
| TapTap（如上架） | 应用分发 | 由 TapTap 按其隐私政策处理 |

除此之外不涉及其他第三方服务。

## 五、未成年人

本作是医学教学模拟，包含疾病、抢救、死亡等内容，**建议 16 岁以上玩家使用**。

我们不面向儿童收集任何信息。如你是未成年人，请在监护人指导下使用。

## 六、你的权利

- **查看**：所有游戏数据都在你设备本地，你随时可以清除
- **删除**：清除浏览器数据 / 卸载应用即彻底删除
- **撤回**：不点"提交反馈"即不产生任何数据外发

## 七、数据安全

游戏不上传个人数据，因此不存在服务器端泄露风险。本地数据的安全取决于你的设备。

## 八、政策更新

本政策如有修改，会在游戏内「隐私政策」页面更新版本号和日期。
