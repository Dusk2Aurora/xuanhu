# 复查与版权说明（v1.35.1）

## 一、技术复查结果

### 通过项（本轮实测）

| 项 | 结果 |
|---|---|
| 随机压力测试 | 400 例 / 27,868 次操作，无崩溃、无 NaN、无越界 |
| 4 床并发推进 2 小时 | 各床独立推进，数值无异常 |
| 抽屉打开时床位条 | 正确让位（opacity=0） |
| 暂停 | 游戏时间冻结（Δt=0.00） |
| 6 小时连续推进 | 无 NaN（病例按预期死亡） |
| 走势图只有 1 个点 | 不崩溃 |
| 术语搜索无结果 | 返回空数组，不报错 |
| 外部依赖 | **零外部资源**：无 CDN、无外部字体、无图片文件（只有自有 JS + HTML） |

### 已知缺陷（按严重度）

1. **子痫前期已停用**：终止妊娠后仍不能稳定出院，机制需重做（`weight:0`，不进生成池）
2. **尿量 uo 是导出量，对容量不敏感**：多个病例的判据已从 uo 改成容量/肌酐/血钾，但参数面板仍把 uo 当独立指标显示，容易误导
3. **更年期症状学缺失**：激素建模了（绝经后雌激素 0.15），但潮热、骨量、睡眠障碍都没做
4. **避孕药只到"凝血倾向数值"**：没有 D-二聚体/血栓事件，风险链断在数值层
5. **极端肺水肿下血氧到地板**：对照与处置都卡在 ~67%，机制测试只能把窗口从 40 min 缩到 22 min 才看得出差别
6. **测试固定身份与性别病例冲突**：测试里宫外孕会被固定成男性（功能不受影响，但语义不对）
7. **多床位存档只存状态**：切床时"未结病例"记为 unknown，不保留当时的诊断上下文
8. **相互作用仅 19 对 / 190 种物质**：覆盖稀疏，大部分组合没有建模

### 建议优先级

1. 子痫前期机制（已停用，属于"半成品"）
2. uo 的语义澄清（要么做成真状态量，要么在面板标注"导出量"）
3. 血栓事件链（D-二聚体 → 肺栓塞）
4. 相互作用扩充（按临床高频组合补到 50 对以上）

## 二、能不能分享 / 有没有侵权风险

> 说明：我不是律师，下面是基于工程事实的风险判断，正式发布前建议找懂知识产权的人过一遍。

### 1. 已核实的事实

- **代码全部自研**：15 个 JS 模块、1 个 HTML，无第三方库、无 CDN、无外部字体、无图片资源
- **文本自写**：病例描述、提示、术语释义、教程都是本会话内撰写的
- **药品名与医学事实**：药物名称、剂量、生理常数属于事实性信息，不受著作权保护
- **图标**：`organs.js` 里有 11 个内联 SVG 器官图标，**没有版权声明来源**

### 2. 主要风险点

| 风险 | 说明 | 建议 |
|---|---|---|
| **器官 SVG 图标来源不明** | 48×48 描边风格，可能是某个图标库或从别处提取。**这是目前唯一的实质性风险** | 换成明确许可的图标集（Health Icons 为 CC0、Lucide 为 ISC、Material Symbols 为 Apache-2.0），或自己重画 |
| **原始 APK 的衍生关系** | 我们是从 THIX「LIFE」的 APK 出发做的重制。玩法/规则（"治疗病人、多床位、给药"）属于**思想**，不受著作权保护；但若沿用了它的具体表达（文案、数值表、UI 布局、素材）就构成侵权 | 已在 v1.35.1 **清掉代码里所有"参照原包/THIX LIFE"的注释**；建议再自查一遍病例文案是否与原作者表述雷同 |
| **游戏名"悬壶"** | 中文成语，通用词汇，著作权上没问题；但若要上架应用商店，需查**商标**（第 9 类软件、第 41 类在线游戏） | 上架前做商标检索；不商用则风险很低 |
| **医学内容的免责** | 这是教学模拟，不是医疗建议 | 建议在启动页/关于页加一句"本作为教学模拟，不构成医疗建议" |
| **分发原始 APK** | 如果把最初的 `base.apk` 一起发出去，那是明确的侵权 | 只分发我们自己的安装包，原始包不外传 |

### 3. 结论

- **个人之间分享、非商业用途**：当前风险较低，前提是**图标换掉**、不附带原始 APK
- **公开上架/商用**：需要做三件事——图标授权、商标检索、以及确认病例文案完全自写（不排除与原作表述雷同的可能）
- 我们没有使用原作的任何代码、素材、音频（原作是 Unity/IL2CPP，我们是纯 Web 重写）
